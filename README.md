# AAPS
**Custom branch with modified sinc kernel (MS or MS1) smoothing plugin integrated**
Smoothing algorithm implementation converted from Java to Kotlin.
The original Java smoothing code is licensed under GNU General Public License (GPLv3) and Creative Commons Attribution-ShareAlike 4.0 (CC-BY-SA 4.0).
Citation: M. Schmid, D. Rath and U. Diebold, 'Why and how Savitzky-Golay filters should be replaced', ACS Measurement Science Au, 2022: https://pubs.acs.org/doi/full/10.1021/acsmeasuresciau.1c00054

User-customisable preferences have also been added for the existing AAPS exponential smoothing plugin.
